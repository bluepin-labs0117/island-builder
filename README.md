# island-builder

3D の島づくり箱庭ゲーム（Three.js 製）。ビルドツール不要で、`index.html` を開くだけで動きます。

## 現在の状態（フェーズ3：地形編集）

- 画面いっぱいの 3D シーン、青い海＋中央の島
- やわらかい光（半球光＋太陽光）とソフトシャドウ
- 斜め見下ろしのカメラ
- **2つのモードを画面右上のボタンで切り替え**
  - **カメラ操作モード**：1本指ドラッグで視点回転 / 2本指ピンチでズーム（PC：左ドラッグ回転・ホイールズーム）
  - **地形編集モード**：指でなぞった場所の地面がなめらかに変形
- **地形編集ツール**（編集モード中に下のボタンで選択）
  - ⛰ 盛る：なぞった所を持ち上げる（山）
  - ⛏ 掘る：なぞった所を沈める（谷）
  - 🪵 ならす：周辺の高さを平均化して平らにする
- **スライダー2つ**：ブラシの幅（半径）／ブラシの強さ
- 地形は連続したハイトマップ。高さに応じて色が変わる（砂浜→緑→岩）。変形した範囲だけを効率更新し、法線も再計算してなめらかな陰影を保つ

水（川・池）、オブジェクト設置、セーブは今後のフェーズで追加予定です。

## ファイル構成

```
index.html           … エントリ。Three.js を CDN（importmap）で読み込む。UIのCSS
js/main.js           … 各モジュールを組み立てて描画ループを回す
js/scene.js          … レンダラー / カメラ / シーン / 海 / ライト・影
js/terrain.js        … 編集できるハイトマップの島（生成・ブラシ適用）
js/terrainEditor.js  … 指/マウス入力 → 地形編集（モード・ブラシ・リング）
js/controls.js       … タッチ・マウスでのカメラ操作
js/ui.js             … モード切替・ツール・スライダーのUI
```

## ローカルで開く方法

ES Modules と importmap を使っているため、`file://` で直接開くと
ブラウザのセキュリティ制限で動かない場合があります。簡易サーバー経由で開いてください。

Python があれば：

```bash
# このフォルダ（island-builder）の中で実行
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

Node.js 派なら：

```bash
npx serve .
```

## GitHub Pages で見る方法

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリ → **Settings** → **Pages**
3. **Build and deployment** の **Source** を **Deploy from a branch** にする
4. Branch を `main`（または公開したいブランチ）の `/ (root)` に設定して **Save**
5. 数十秒〜数分後に表示される URL（`https://<ユーザー名>.github.io/island-builder/`）を開く

CDN から Three.js を読み込むので、追加のビルド作業は不要です。

## 動作環境

- インターネット接続（Three.js を CDN から取得するため）
- 最近のスマホ／PC のブラウザ（WebGL 対応）
