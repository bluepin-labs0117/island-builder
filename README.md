# island-builder

3D の島づくり箱庭ゲーム（Three.js 製）。ビルドツール不要で、`index.html` を開くだけで動きます。

## 現在の状態（フェーズ11：家のディテール向上・窓ガラス・石の基礎）

- 窓：キットの窓インサート `Window_Wide_Flat1`（木枠＋ガラス）を各窓開口に挿入。穴あきを解消。
  ガラスは見やすい薄青の半透明に調整（小さなパネルのみ・depthWrite無効で軽量）。
- ディテール：四隅の木柱 `Corner_Exterior_Wood`、足元の木ビーム `Wall_BottomCover`、ドア枠
  `DoorFrame_Flat_WoodDark`＋金具付き扉 `Door_2_Flat` を追加。家3はハーフティンバー壁
  `Wall_Plaster_WoodGrid` で差別化（家1=漆喰小屋／家2=レンガ／家3=木組み）。
- 基礎：灰色4本柱を廃止し、家の底面形状に沿った**石材プリンス（1棟1ボックス）**に変更。四隅と
  中心の地面の最低点まで伸ばして隙間を埋め、家を地面に自然に接地（浮き解消）。
- 軽量化：マテリアル単位でマージ（1棟あたり描画は数メッシュ）。重いマップは読込スキップ＋
  BaseColorを512pxへ縮小を継続。透明は窓のみ。
- パーツの原点はキットのモジュール設計で壁と共通のため、壁と同じ pos/rotY で重ねるだけで嵌る。

## 現在の状態（フェーズ10：家を実3Dモデルへ差し替え）

- 設置の「家」を Quaternius「Medieval Village MegaKit」(CC0) の実モデルへ差し替え。
- このキットは**完成した家モデルが無いモジュラー式**のため、床+壁+屋根を**データ駆動で
  固定合成した「家プレハブ」を3種**用意（将来の建築システムに発展しやすい構造）。
- 設置パレットで家を選ぶと家1/2/3を選択可。接地・垂直配置・土台（基礎）・回転・削除・
  セーブ（種類含む）は既存ロジックを流用。`GLTFLoader` で非同期ロードし、読み込み中は
  簡易な箱で表示→完了後に実モデルへ差し替え（アプリは固まらない／失敗時はコンソール出力）。
- スマホ向け軽量化：テクスチャは元2048pxと過大なため、**重いマップ(法線/粗さ等)は読み込み
  をスキップ**し、**BaseColorのみ512pxへ実行時縮小**してGPUメモリを大幅削減。
- 開口の塞ぎ：モジュラー壁は窓/ドアが開いて向こうが透けるため、**窓ガラス面（不透明の薄青／
  透明描画コスト0）**・**ドア板**・**内部の暗いコア箱**を全プレハブに自動付与し、空洞・貫通を解消。
- パスは相対（`./assets/buildings/glTF/...`）でサブフォルダ配信でも動作。

## 現在の状態（フェーズ9：簡易リアルタイム流体・水源・溝）

- **水源と流れ**：「💧水源」ツールで地面をタップすると水源を設置（再タップで削除、
  「🚱全消し」あり）。水は高さマップ上のセル法で**低い方へ流れ**、掘った溝に沿い、
  無ければ斜面に沿って**海まで流れて消える**。本物の流体計算ではなく軽量なセル法
- **溝ツール**：「〰️溝」でなぞった経路に細く深い谷（水路）を彫れる
- **軽量化（スマホ優先）**：流体は地形(128)とは別の粗い格子で、描画と切り離して
  低頻度更新。画質連動で 高=96格子/18Hz・中=64/16・低=48/12。低画質でも破綻しない
- 水源と水の状態はセーブされる（水は水源から数秒で再形成）

※技術評価：セル計算自体は軽く（〜数百万演算/秒）、ボトルネックは水面メッシュの
GPU再アップロード。そのため格子を粗く・低頻度更新にして現実的な負荷に収めている。

## 現在の状態（フェーズ8：水の表現を強化）

- **空の反射＋きらめき**：水面に空のグラデーション環境マップ（envMap）を反射させ、
  低めの粗さで太陽のきらめきを出す。画質「低」では反射を切って軽量化
- **流れの強化**：法線マップを一定方向に大きく・速くスクロールさせ、反射が揺れて
  水が動いて見える（斜面の水路も流れる演出。本物の流体計算はしない）
- **岸辺・深度**：島まわりの浅瀬〜深場を地形側の水面メッシュで描画。浅い所は明るく
  透明（砂底が透ける）、深い所ほど濃紺で不透明に。岸辺がなじみ「後付け感」を低減。
  遠景の海は板を少し沈めて浅瀬では隠れるようにし、二重描画を抑制

## 現在の状態（フェーズ7：場所ごとの水・岩質感・画質・画質設定）

- **場所ごとの水面**：海（共通 y=0）に加え、内陸の水は地点ごとに水面の高さを
  持つ（`pool`）。海面より高い標高にも泉・水路を作れる。「水」ツールでなぞると
  浅い水底を彫って水を張り、斜面をなぞると水面が下流へ段々に下って川に見える。
  水面は流れる向きにスクロールして「流れている」感を演出。内陸水の状態もセーブ
- **岩の質感**：山肌の岩を標高＋傾斜で出し、頂点カラーに濃淡のムラを付与。
  設置物の岩は頂点をノイズで動かしてゴツゴツに、色も明暗ムラ
- **画質向上**：ACES トーンマッピング、太陽光＋半球光＋補助光の調整、ソフトシャドウ、
  地形の簡易AO（谷を暗く）でのっぺり感を低減
- **画質設定（高/中/低）**：右上ボタンで切替。影解像度・ピクセル比・AO・水の
  ディテール・露出・アンチエイリアスをまとめて変更。設定はセーブされ次回も維持。
  初回は端末性能から自動推定

## 現在の状態（フェーズ6：水ツール・標高カラー・ペイント・画質向上）

- **木が垂直に**：木は家と同じく常に垂直。岩のみ地形の傾きに沿う
- **カメラの平行移動（パン）**：1本指=回転 / 2本指ドラッグ=パン / ピンチ=ズーム（PCは右ドラッグでパン）
- **「水」ツール**：地形編集ツールに追加。なぞった所を水位より少し下まで掘って水で満たす（川・池を自由に描ける）。「盛る」で水位より上げれば水は消える
- **標高に応じた山肌**：低い順に 砂浜→草→岩肌（土・茶〜灰）→雪。標高でなだらかに混ざり、急斜面は岩肌寄り。高く盛るだけで岩山・雪山になる
- **地表ペイント**：「🎨 地表」ツール＋材質（草/砂/岩/雪）。塗った所は自動色を上書きして固定。塗っていない所は自動のまま。ペイントもセーブされる
- **水の見た目向上**：ターコイズ寄りの色＋半透明で浅い所は明るく深い所は暗く、さざ波を斜めに流して川らしく
- **画質向上**：ACES トーンマッピング、太陽光＋半球光＋弱い補助光のバランス調整、2048 のソフトシャドウで自然な立体感

セーブ対象＝地形の高さ・手動ペイント・設置オブジェクト（閉じて開いても復元）。

## 現在の状態（フェーズ5：水の表現＋家の土台）

- **水（川・池・湖）**：水位（海面 y=0）に半透明の青い面を1枚。水位より低い場所は
  水面に隠れ、半透明越しに地形が透けて沈んで見える。地形を「掘る」と溝が川に、
  窪地が池・湖になる（内陸でも水位より低ければ水になる）。さざ波はスクロールする
  法線マップで軽く表現
- **家の土台（基礎）**：家を斜面や崖に置くと、家の四隅と真下の地面の隙間を灰色の
  四角い柱（基礎）が自動で埋める。家は常に垂直のまま、宙に浮かず崖からせり出しても
  自然に見える。家の回転・削除・地形変更に追従

## 現在の状態（フェーズ4：オブジェクト設置＋セーブ）

- 画面いっぱいの 3D シーン、青い海＋中央の島、半球光＋太陽光＋ソフトシャドウ
- **3つのモードを画面上部のボタンで切り替え**（操作が干渉しないよう排他）
  - 🎥 **カメラ操作**：1本指で回転 / 2本指ピンチでズーム（PC：左ドラッグ・ホイール）
  - ✏️ **地形編集**：指でなぞって地面をなめらかに変形
  - 🌲 **設置**：地面タップで物を置く（カメラ操作も併用可）
- **地形編集**（編集モード）
  - ツール：⛰ 盛る / ⛏ 掘る / 🪵 ならす
  - スライダー：ブラシの幅・強さ
  - 広いハイトマップ。高さで色が変わる（砂浜→緑→岩）。縁に近づくほど自然に
    海面下へ沈むので、端を盛っても破片が浮かず常に海に浮かんで見える
- **オブジェクト設置**（設置モード）
  - パレット：🪨 岩 / 🌳 木 / 🏠 家（仮の簡易3D）。地形の高さに自動接地
  - 家は常に垂直、岩・木は地形の傾きに少し沿う
  - 置いた物をタップで選択 →「↻ 回転」「🗑 削除」
  - 上限300個。同じ種類はインスタンシングで軽量描画
- **セーブ／ロード**
  - 編集のたびに端末内（localStorage）へ自動保存、起動時に前回の島を自動復元
  - 「🗑 リセット」で確認のうえ初期状態に戻す

水（川・池）は今後のフェーズで追加予定です。

## ファイル構成

```
index.html           … エントリ。Three.js を CDN（importmap）で読み込む。UIのCSS
js/main.js           … 各モジュールを組み立て・モード管理・自動保存/復元
js/scene.js          … レンダラー / カメラ / シーン / 海 / ライト・影
js/terrain.js        … 編集できるハイトマップの島（生成・ブラシ・縁の海面復帰・接地問い合わせ）
js/terrainEditor.js  … 地形編集の入力（ブラシ・リング・線補間）
js/objects.js        … 設置オブジェクト管理（種類ごとにインスタンシング）
js/placeEditor.js    … 設置モードの入力（タップで設置/選択・回転・削除）
js/storage.js        … localStorage への保存・復元（自動保存はデバウンス）
js/controls.js       … タッチ・マウスでのカメラ操作
js/ui.js             … モード切替・ツール・パレット・スライダー・トーストのUI
```

## ローカルで開く方法

ES Modules と importmap を使っているため、`file://` で直接開くと
ブラウザのセキュリティ制限で動かない場合があります。簡易サーバー経由で開いてください。

Python があれば：

```bash
# このフォルダ（island-builder）の中で実行
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

Node.js 派なら：

```bash
npx serve .
```

## GitHub Pages で見る方法

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリ → **Settings** → **Pages**
3. **Build and deployment** の **Source** を **Deploy from a branch** にする
4. Branch を `main`（または公開したいブランチ）の `/ (root)` に設定して **Save**
5. 数十秒〜数分後に表示される URL（`https://<ユーザー名>.github.io/island-builder/`）を開く

CDN から Three.js を読み込むので、追加のビルド作業は不要です。
